# Task 3 — BookFinder REST API Project

## Objective
Use a public REST API to fetch and display data dynamically.

## Project
BookFinder is a responsive book-search interface using live data from the Open Library Search API.

## API Used
**Open Library Search API:** `https://openlibrary.org/search.json`

JavaScript uses the browser Fetch API to send a search request and display book title, author, publication year and cover data.

## Requirements Covered
- Public REST API
- Fetch API
- Dynamic API data
- Loading state
- Error state
- Search feature
- Responsive interface

## Technologies
HTML5, CSS3, JavaScript, Fetch API and DOM manipulation.

## Hosted Link
`https://amtul-coder.github.io/internspark-tasks/Task-3-BookFinder/`

## Short Write-up
The application sends an HTTP request to the Open Library Search API using JavaScript `fetch()`. The JSON response is processed and converted into book cards in the DOM. Loading and error messages provide user feedback, while the search feature lets users request different titles, authors or topics dynamically.

## Visual Theme
The interface uses a dark background with neon green highlights and deep red accents for a distinctive modern look.
