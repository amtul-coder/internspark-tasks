# Task 1 – Responsive Portfolio Website

## Project Overview

This project is a responsive personal portfolio website created as part of the InternSpark Web Development Internship.

The website presents a clean and modern interface with sections for introducing the developer, displaying skills and projects, and providing contact information.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and creative visual theme
- Navigation bar with smooth scrolling
- Home/Hero section
- Skills section
- Projects section
- Contact section
- Mobile-friendly navigation menu
- Interactive buttons and navigation elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox and CSS Grid
