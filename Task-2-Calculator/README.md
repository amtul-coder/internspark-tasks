# Task 2 — NeonCalc JavaScript Mini Project

## Overview
NeonCalc is a responsive mini calculator built for the InternSpark JavaScript Mini Project task. It uses JavaScript event handling and DOM manipulation to provide an interactive calculator experience.

## Features
- Addition, subtraction, multiplication and division
- Decimal calculations
- Percentage conversion
- Delete and clear controls
- Division-by-zero handling
- Keyboard input support
- Responsive neon/magenta visual theme

## Technologies
- HTML5
- CSS3
- JavaScript (DOM manipulation and event handling)

## Files
- `index.html` — page structure and calculator controls
- `style.css` — responsive neon/magenta styling
- `script.js` — calculator logic and DOM interaction

## How to run
Open `index.html` in a browser, or use a local development server such as VS Code Live Server.
